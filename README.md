# Z8 Transfer

面向 **Nikon Z8** 的 Android 照片与视频传输 App，支持 USB 有线连接和 Wi-Fi 热点直连，可浏览相机文件、全屏预览、选择下载原文件，支持按能力开放的遥控拍照与实时取景，并在相机开放删除能力时通过 USB 或 Wi-Fi 删除相机文件。

使用 **Kotlin + Jetpack Compose** 开发，当前优先适配 **小米 17 Pro Max**。

> 当前版本：**0.8.0（开发测试版）**。遥控页扩展分类参数控制与连接能力报告。新版默认采用 Android 系统 MTP 连接。自动化检查已通过，Z8 与目标手机的新版 USB 回归、Wi-Fi 兼容性和实际传输速度仍待实机验证。

## 功能

| 功能 | 当前实现 |
| --- | --- |
| USB 连接 | 默认系统 MTP；可手动选择实验性标准 PTP |
| Wi-Fi 连接 | 相机 AP 热点直连、地址自动推断、手动 IPv4 与端口 |
| 功能导航 | 首页选择「遥控拍摄」或「下载照片」；仅下载页读取相册 |
| 文件浏览 | 存储卡、文件名、日期、RAW/JPEG 等格式筛选，支持 1–6 列网格和 6 种排序 |
| 相机遥控 | 独立页面，连接后直接取景、对焦、拍照，不依赖相册加载；按 Wi-Fi / 标准 PTP 能力开放 |
| 拍摄参数 | 65 项设置/状态目录，包含 P/A/S/M、曝光、AF、画质、色温、释放及视频参数；按相机能力开放并回读确认，保留未适配项的只读状态 |
| 全屏预览 | 上滑收起工具栏，点按全屏、左右切换，照片双指缩放和双击放大，可开关真实对焦框 |
| 批量选择 | 勾选、长按后拖动批选/取消、边缘自动滚动、全选当前筛选结果 |
| 原文件下载 | 流式保存、进度与速度显示、后台通知、重复导入检查、失败项重试 |
| 相机文件删除 | USB / Wi-Fi 按相机能力开放，逐项复核并二次确认，支持列表批量删除及预览页单张删除，可选连带删除 RAW 的同名 JPEG |
| 快速翻页 | 拖动网格右侧手柄跳转位置，显示当前序号与总数 |
| 连接诊断 | 展示错误详情，可复制设备和连接信息用于排查 |

文件是否可见取决于相机固件及连接模式暴露的内容。App 无法读取相机未提供的文件。

## 当前限制

- **系统 MTP 暂不传输大于等于 4 GiB、大小为 `0xffffffff` 标记或大小未知的文件**，避免生成截断副本；这些文件仍可出现在列表中。
- 标准 PTP 为实验功能。目标手机曾出现 USB 命令发送失败，尚未解决，不作为当前手机的大视频传输方案。
- **不支持 N-RAW / ProRes RAW 原生解码**。能够显示或下载文件，不代表能够在手机上播放。
- Wi-Fi 尚待真机验证；暂不支持电脑 / PIN 配对、STA 专有认证、蓝牙唤醒及自动重连。
- 暂无单文件断点续传和进程退出后的队列恢复；点击停止会在当前文件完成后停止后续任务。
- 目前没有真实设备的 USB / Wi-Fi 速度对比数据，也未验证其他机型的兼容性。

## 连接与使用

### USB 有线连接（优先）

1. 用支持数据传输的数据线连接手机与 **Z8 的 USB 数据接口**，相机的 USB 数据连接选择 **MTP/PTP**。
2. 退出其他正在访问相机的 App，避免同时占用设备。
3. 打开 App，保持 **系统 MTP（推荐）**，点击连接并在 Android 弹窗中允许 USB 访问。
4. 连接后浏览文件；点按预览，勾选或长按选择，再下载原文件。
5. 上滑可收起顶部工具栏；向下拉或点击「展开工具栏」恢复。

一次连接只使用选中的驱动，失败后不会自动切换到另一驱动。实验性标准 PTP 只能在未连接时主动选择，新进程启动恢复默认系统 MTP。

### Wi-Fi 热点直连（测试）

1. 在相机打开「**网络菜单 → 连接至智能设备 → Wi-Fi 连接（AP 模式）→ 建立 Wi-Fi 连接**」。菜单名称可能随固件不同。
2. 在手机系统 Wi-Fi 设置中连接相机显示的热点并输入密码；提示无法上网时，选择保持连接。
3. 退出 SnapBridge 等占用相机连接的 App，返回本 App，打开「Wi-Fi 连接」。
4. 优先使用自动地址；失败时填写相机实际局域网 IPv4 地址，默认端口为 **15740**。
5. 连接后停留在功能首页；选择「遥控拍摄」可直接进入取景，选择「下载照片」才读取列表、预览和选择下载。相机声明支持 DeleteObject 时可确认后删除。断开后需要手动重连。

App 将相机通信的 socket 单独绑定到 Wi-Fi，以适应手机同时开启蜂窝数据的情况；当前需要手机与相机地址处于可直接访问的同一网段。

## 格式与预览

| 文件类型 | 列表与下载 | 预览方式 |
| --- | --- | --- |
| JPEG、HEIF / HIF / HEIC | 支持，受连接方式及大小限制 | 缩略图；不超过 64 MiB 时尝试缓存原文件，解码最长边约 2560 像素 |
| NEF 照片 RAW | 支持，受连接方式及大小限制 | 优先使用同卡、同目录、同名 JPEG，否则尝试读取 NEF 内嵌 JPEG（NEF ≤ 192 MiB）；失败时回退相机缩略图；无完整 NEF 解码 |
| NEV（N-RAW） | 支持显示；下载受大文件限制 | 可使用同卡、同目录、同名 MP4 代理；无 N-RAW 解码 |
| MOV、MP4 | 支持，受连接方式及大小限制 | 优先使用同名 MP4 代理；通过 Android 播放器尝试播放，受实际编码支持限制 |
| 其他普通文件 | 相机暴露时可列出与下载 | 不承诺预览支持 |

视频临时预览的单文件上限为 **512 MiB**。MOV 是容器格式，不能仅凭扩展名判断是否为 RAW 或是否可播放。预览缓存不会替代正式下载。

### 独立功能页（0.6.0）

- 连接完成后停留在首页，不自动扫描存储卡照片。可以先选择功能页再连接相机。
- 「遥控拍摄」直接打开独立取景控制页面；无需加载相册，也不会自动触发快门。点击页面内「拍照」才发送拍照指令。
- 「下载照片」才开始读取相片列表；重新进入该页会更新列表，同一页重复点击不会重复启动扫描。
- 列表读取中可切换遥控：先完成当前相机响应并取消后续枚举，再开启取景，不必等待整张卡扫描结束。
- 拍照后返回首页、退出遥控或切到后台均不自动扫描；在遥控页点击「下载照片」会先结束取景，再读取相册。
- 原片下载或删除任务运行时暂不切换页面；这些操作与单纯的列表扫描分开处理。

### 相机遥控与实时取景

1. 建议先连接相机 Wi-Fi。将相机切到照片单张拍摄模式；连接成功后选择「遥控拍摄」，直接进入取景，无需加载相册。
2. 相机声明支持实时取景时自动拉取画面，显示收到的实际帧数和帧率；支持「暂停/开启取景」「自动对焦」「拍照前自动对焦」。取景请求上限约 8 次/秒，实际帧率和延迟取决于相机、网络及解码速度。
3. 点击「拍照」后向相机存储卡发送一次拍照指令，不自动重试快门。照片格式、曝光和释放模式沿用相机设置。遇到响应丢失或完成状态不确定时禁止继续拍照，需先检查相机或退出后刷新，避免重复曝光。
4. 「返回首页」会结束取景并释放本 App 取得的遥控模式，不读取照片；选择「下载照片」后才重新扫描文件，保留仍然有效的选择。可在列表下载原片。实时取景帧只显示在屏幕中，不自动保存、录制或替代原片下载。
5. 页面打开时保持屏幕常亮；退出、进入后台或连接断开时清理取景会话。暂停或长时间没收到新帧时显示提示，保留的旧帧不会标成持续更新。

### 分类遥控设置（0.8.0）

1. 进入遥控页点击「拍摄参数」才读取，进入遥控本身不等待相册或参数加载。「模式/曝光」紧凑显示 P/A/S/M、快门、光圈、ISO、曝光补偿和白平衡。
2. 横向类别栏可切换 ISO/测光、对焦、画质、色彩、释放、闪光、取景、视频、状态。只请求当前组，避免一次读取全卡或全部属性。
3. 每次修改前复核可写权限与可用值，只发一次写入，随后回读当前组；模式切换会更新快门、光圈等限制。机身调整后点「刷新」。回读不一致显示实际值和提示。
4. 色温允许按机身范围/步长输入，图像尺寸直接选择机身返回的分辨率。连拍/自拍会改变快门行为；一次指令不保证只生成一张照片。视频页只调参数，需在机身切模式，未提供录像开始/停止。
5. 目录 65 项中有 52 项条件式写入路径、13 项保留只读，实际可调数量由当前连接决定。优化校准、主体侦测、部分速度/卡槽策略等仍需进一步实机适配，未声明支持的项目禁用。**尚未覆盖 Z8 的全部功能。**
6. 「能力 → 复制完整报告」可导出已发现属性、目录匹配情况和发现失败原因，供后续适配；不扫描照片，不开放任意属性写入。

完整逐项策略及未接入功能见 [CAMERA_CONTROLS.md](CAMERA_CONTROLS.md)。参数操作期间快门暂不可用，完成后继续取景。B 门/Time 保留机身控制；不会自动改变照片/视频、自动 ISO 或白平衡模式来配合其他设置。

| 连接 | 遥控拍照 / 取景 |
|---|---|
| Wi-Fi PTP/IP | 按当前连接声明的操作能力启用；设备拒绝时显示返回错误 |
| USB 标准 PTP（实验） | 同一遥控协议；保留原有连接限制，仍需实机验证 |
| USB 系统 MTP（默认） | Android 公开 MTP 接口不提供本项目需要的遥控指令；提示使用 Wi-Fi 或手动改选标准 PTP，不自动更换驱动 |

只开放相机当前连接声明支持的指令。未实现触屏指定对焦点、录像开始/停止、Bulb 开始/终止或后台取景；其他未接入项见适配矩阵。没有连接真实相机的自动化检查不能证明目标固件已开放无线控制。

### 单张预览删除（0.5.0）

预览底部增加「删除此文件」，点击后先显示永久删除确认框。RAW 可勾选同卡、同目录的同名 JPEG。执行成功后显示下一张仍存在的文件，最后一张删除后返回列表；失败保留当前文件并显示原因。相机不支持删除、连接断开或任务运行中，按钮不可用。

### 新增浏览操作（0.4.0）

- 「排序」提供拍摄时间、文件名、大小的升降序；只影响显示顺序，保留已选文件。
- 「RAW」「JPEG」独立筛选照片；N-RAW 仍属于视频筛选。
- 「列数」可选 1–6 列，4–6 列采用紧凑缩略图。点击照片预览；长按后保持按住并拖动可连续选择，起点已选时连续取消。反向拖动缩小范围时恢复起始选择，靠近上下边缘自动滚动。
- 右侧「↕」手柄可拖动跳转；翻页遵循当前筛选和排序。工具栏上滑隐藏的操作保留。
- 全屏预览顶部可切换「显示/隐藏对焦框」，开关在本次界面中保留。读取 Nikon AFInfo2 0400 中的真实矩形坐标，随图片方向、缩放和平移同步；绿色/红色反映元数据中的对焦结果。支持可读取的 JPEG，以及带内嵌 JPEG 或配套 JPEG 的 NEF。没有坐标的 AF 点掩码、其他版本、HEIF、视频和仅有相机缩略图时不绘制，并显示提示。尚需用户原始照片验证位置精度。
- 原图和对焦数据首次读取可能需要缓存原文件，Wi-Fi 下耗时取决于文件大小；此缓存不属于正式下载。

### 保存位置与完整性

通过 Android MediaStore 保存到手机共享存储，目录保留相机、存储卡和原始文件夹的区分：

| 文件 | 保存目录 |
| --- | --- |
| JPEG、NEF、HEIF 照片 | `Pictures/Z8Transfer/<相机标识>/<存储卡>/<原始目录>/` |
| MOV、MP4 及其他已识别的视频 | `Movies/Z8Transfer/<相机标识>/<存储卡>/<原始目录>/` |
| NEV 及其他文件 | `Download/Z8Transfer/<相机标识>/<存储卡>/<原始目录>/` |

- 以原始字节流传输，不压缩、不转码。
- 已知大小的文件需通过实际字节数和协议 / 驱动结果检查后才发布；失败时回滚未完成副本。
- 支持根据来源元数据及本地副本的存在与长度检查重复导入；这不等同于源文件与副本的内容哈希校验。
- 对支持未知长度流的实验连接，会标记未独立验证源文件大小，并且不自动去重。
- 使用前台服务显示后台传输通知；实际后台表现仍受手机系统策略影响。

### 删除相机文件

USB 和 Wi-Fi 连接均在相机声明支持删除时启用。确认界面列出固定文件清单，需要明确确认永久删除；执行前复核连接、存储卡、文件元数据及保护状态。

默认只删除所选相机文件。选中 RAW（NEF）时，可在确认框勾选「同时删除同名 JPEG」；匹配限定同一连接、同一存储卡卷、同一目录，文件名主干忽略大小写，并兼容 .jpg / .jpeg。勾选后会更新完整删除清单和数量，并要求重新确认。不会从 JPEG 反向匹配 RAW，不连带删除视频代理或手机已有副本。每个文件独立执行，部分失败会显示结果，不保证 RAW/JPEG 同时成功。不支持目录或通配删除，失败不会自动重试。**相机原文件删除不可撤销，测试前请先备份。**

## 问题排查与反馈

| 现象 | 建议 |
| --- | --- |
| USB 无法读取设备信息或存储卡 | 确认数据线、USB 数据接口及 MTP/PTP 模式，退出其他相机 App，拔线重连并保留默认系统 MTP |
| 标准 PTP 提示命令发送失败 | 属于已知待排查问题，重新建立连接后使用默认系统 MTP；切换驱动不会自动修复底层 USB 问题 |
| Wi-Fi 超时或拒绝连接 | 确认保持连接相机热点、使用智能设备 AP 模式，检查实际 IP / 端口并退出其他相机 App |
| RAW 视频有文件但无法播放 | 使用兼容播放器或同名 MP4 代理；本 App 未实现 N-RAW / ProRes RAW 解码 |
| 大视频无法下载 | 先确认当前连接的大文件限制；系统 MTP 不支持本版限制范围之外的文件 |

反馈时请附上 App 版本、相机固件、手机型号与 Android 版本、连接方式、复现步骤及「查看详情 → 复制信息」的错误内容。请勿公开 Wi-Fi 密码、设备序列号等个人信息。
